# Task 3: SQL for Data Analysis

## Objective

The objective of this task was to use SQL queries to extract,
analyze and summarize data from a relational database.

## Tool Used

- SQLite
- DB Browser for SQLite

## Database

The database contains three tables:

1. Customers
2. Products
3. Orders

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Aggregate Functions
- SUM()
- AVG()
- Subqueries
- Views
- Indexes

## Analysis Performed

The queries were used to:

- Retrieve customer and product information
- Filter records
- Sort products by price
- Calculate total and average quantities
- Group orders by customer
- Combine information from multiple tables
- Find products above average price
- Create a customer order summary view
- Create an index for query optimization

## Outcome

This task helped in understanding SQL-based data analysis,
relational tables, joins, aggregation, subqueries, views and indexing.
